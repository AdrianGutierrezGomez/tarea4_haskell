# Tarea 4: Haskell
Tarea de Programación Avanzada
Adrián Gutiérrez Gómez - Javier Antonio
## Instrucciones 
Programa en el lenguaje en Haskell las siguientes funciones:
1. Una función para sumar matrices. Las matrices pueden ser representadas como una lista de
listas.
2. Una función que indique que dos listas son iguales aunque los elementos aparezcan en
distinto orden (conjuntos en Haskell).
3. Define la función invertir una lista usando la función de plegado por la derecha y define otra
usando otra plegado por la izquierda.
4. Define una función para ordenar dos listas que recibe como argumentos.
